# سیستم طراحی، پالت رنگ و سیاست چیدمان فیزیکی (Design System & Physical Layout Policy)

این سند مشخصات فنی کامل سیستم طراحی بصری پلتفرم گیمینگ **DrGame-Ecommerce** را بر مبنای توکن‌های استخراج‌شده از سورس مرجع `sources/figr-source/styles.css`، استانداردهای تایپوگرافی، آیکونوگرافی اختصاصی و همچنین قانون بنیادین **چیدمان فیزیکی ثابت (Fixed Physical Layout Policy)** تدوین می‌نماید.

## ۲. سیاست چیدمان فیزیکی ثابت (Fixed Physical Layout Policy - R11 & Section 6.1)

پلتفرم گیمینگ DrGame از یک اصل مهندسی صریح و تزلزل‌ناپذیر پیروی می‌کند:
> **قانون جهت فیزیکی ثابت:** جایگاه تمام ساختارها، ستون‌های سایدبار، نوار فیلتر و پنل‌ها به صورت **فیزیکی (Physical Left / Physical Right)** تعریف می‌شود و تغییر زبان سایت (از جمله سوئیچ به زبان‌های راست‌به‌چپ مانند فارسی و عربی یا چپ‌به‌راست مانند انگلیسی و فرانسوی) **هرگز نباید موقعیت ستون‌ها یا چیدمان کلان صفحه را قرینه یا جابجا (Mirror) کند.**

### ۲.۱. دلایل معماری چیدمان غیرقرینه
۱. **ثبات حافظه بصری گیمر (Gamer Muscle Memory):** گیمرها در تمام دنیا ساختار فروشگاه‌ها، فیلترها و داشبوردهای استیم، پلی‌استیشن و اپیک‌گیمز را در نقاط مکانی ثابت تجربه کرده‌اند.
۲. **وفاداری به سند بصری مرجع:** بر اساس تصویر مرجع `sources/pics/games.jpg`، فیلترهای پیشرفته در سمت چپ فیزیکی و ماژول‌های اطلاعاتی در سمت راست قرار دارند. این چیدمان در تمام ۳۰ زبان سایت یکسان خواهد ماند.
۳. **رفتار متن در برابر رفتار اسکلت صفحه:**
   - **اسکلت صفحه (Page Shell Grid):** از کلاس‌های فیزیکی مشخص مانند `grid-cols-[280px_1fr_300px]` با ستون‌بندی ثابت استفاده می‌کند.
   - **جریان متن درون کامپوننت‌ها (Component Text-Run):** هر کامپوننت متناسب با زبان جاری (`dir="rtl"` یا `dir="ltr"`) تراز متن و جهت خوانش پاراگراف‌ها را تنظیم می‌نماید (تصمیم `OD-7`). برچسب‌ها و آیکون‌ها درون یک سطر با توجه به جهت زبان چیده می‌شوند اما کلیت بلاک در جایگاه فیزیکی خود باقی می‌ماند.

### ۳.۲. گلیف‌های وکتور اختصاصی کنترلر پلی‌استیشن (PlayStation Vector Glyphs)

نمادهای اختصاصی دسته کنسول درون کامپوننت `PlayStationGlyph.tsx` به صورت SVG خالص با نسبت ابعاد ۱:۱ طراحی شده و در حالت‌های کنسول و مشخصات بازی به کار می‌روند:

```tsx
// frontend/src/components/PlayStationGlyph.tsx
export type PSGlyphType = 'cross' | 'circle' | 'square' | 'triangle' | 'dpad' | 'l1' | 'r1' | 'l2' | 'r2' | 'options';

export const PSGlyph = ({ type, className = "w-4 h-4 inline-block" }: { type: PSGlyphType; className?: string }) => {
  switch (type) {
    case 'cross': // ✕ آبی نئونی
      return <svg viewBox="0 0 24 24" className={`${className} text-[#3b82f6]`} fill="none" stroke="currentColor" strokeWidth="3"><line x1="18" y1="6" x2="6" y2="18"/><line x1="6" y1="6" x2="18" y2="18"/></svg>;
    case 'circle': // ○ قرمز نئونی
      return <svg viewBox="0 0 24 24" className={`${className} text-[#ef4444]`} fill="none" stroke="currentColor" strokeWidth="3"><circle cx="12" cy="12" r="8"/></svg>;
    case 'square': // □ صورتی/بنفش نئونی
      return <svg viewBox="0 0 24 24" className={`${className} text-[#ec4899]`} fill="none" stroke="currentColor" strokeWidth="3"><rect x="4" y="4" width="16" height="16" rx="2"/></svg>;
    case 'triangle': // △ سبز نئونی
      return <svg viewBox="0 0 24 24" className={`${className} text-[#22c55e]`} fill="none" stroke="currentColor" strokeWidth="3"><polygon points="12 4 21 20 3 20"/></svg>;
    default:
      return null;
  }
};
```

## ۴. نقاط شکست واکنش‌گرا و دسترسی‌پذیری (Breakpoints & Accessibility)

مطابق با فایل مرجع `sources/figr-source/styles.css` (خطوط ۱۶۶۵ تا ۱۸۳۷)، سیستم گرید و ریسپانسیو بر اساس ۵ نقطه شکست استاندارد تنظیم شده است:

| نقطه شکست (Breakpoint) | حداقل / حداکثر عرض | رفتار چیدمان فروشگاه و کامپوننت‌ها |
| :--- | :--- | :--- |
| `2xl` / دسکتاپ عریض | `1400px+` | چیدمان کامل ۳ ستونه: فیلتر چپ (۲۸۰px)، کاتالوگ ۳ کارته (۱fr)، سایدبار راست (۳۰۰px) |
| `xl` / دسکتاپ استاندارد | `1200px - 1399px` | ۳ ستونه با کارت‌های ۲ تایی در ردیف یا اسکیل فیلتر چپ به ۲۵۰px |
| `lg` / لپ‌تاپ و تبلت افقی | `992px - 1199px` | سایدبار راست جمع شده و به صورت تب یا زیر کاتالوگ قرار می‌گیرد؛ فیلتر چپ حفظ می‌شود |
| `md` / تبلت عمودی | `768px - 991px` | فیلتر چپ به صورت کشویی آف‌کانواس (Drawer) درمی‌آید؛ کاتالوگ ۲ کارته تمام‌عرض می‌شود |
| `sm` / موبایل هوشمند | `480px - 767px` | کاتالوگ ۱ کارته تمام‌عرض، نوار فیلتر شناور پایین صفحه |
| `xs` / موبایل کوچک | `< 480px` | ساده‌سازی متاداده‌های کارت بازی، پنهان‌سازی پیش‌نمایش هاور |

### استانداردهای دسترسی‌پذیری (Accessibility & Motion Standards)
- **کنتراست رنگ متن (WCAG 2.1 AA):** تمام متن‌های اصلی با نسبت کنتراست بالای `7:1` نسبت به سطوح پس‌زمینه تیره رندر می‌شوند (`#f1f5f9` روی `#0f1016`).
- **پشتیبانی از کاهش انیمیشن (`prefers-reduced-motion`):** در صورت فعال بودن تنظیمات کاربر یا سیستم، انیمیشن‌های پس‌زمینه شناور (Poster Marquee) و ترنزیشن‌های سنگین هاور غیرفعال شده و با تغییر وضعیت ساده جایگزین می‌شوند.
