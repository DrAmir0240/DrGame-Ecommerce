# گزارش ۲: زیرساخت جامع چندزبانه i18n (فارسی، انگلیسی، عربی)

## ۱. هدف و صورت مسئله
* پیاده‌سازی کامل سیستم بین‌المللی‌سازی (i18n) در فرانت‌اند برای پوشش زبان‌های **فارسی (`fa`)**، **انگلیسی (`en`)** و **عربی (`ar`)**.
* پشتیبانی همزمان از جهت‌های خوانش **RTL** و **LTR**، فونت‌های بومی، تاریخ‌های تقویمی (شمسی / میلادی)، ارقام فارسی/عربی، و مدیریت اصولی ترجمه‌های بخش فروشگاه و پنل ادمین بدون افت پرفورمنس.

---

## ۲. معماری پیاده‌سازی‌شده

```
frontend/src/i18n/
├── config.ts              # تعاریف زبان‌ها، جهت‌ها و رجیستری منابع
├── I18nProvider.tsx        # کانتکست React، مدیریت کوکی/LocalStorage و همگام‌سازی DOM
├── format.ts              # قالب‌بندی ارقام، قیمت‌ها (تومان/دلار)، تاریخ‌ها و حجم فایل
├── index.ts               # نقطه ورود اصلی و Singleton دسترسی به متدها
├── locales/               # فایل‌های تجمیعی زبان‌ها (fa.json, en.json, ar.json)
└── messages/              # ماژول‌های تفکیک‌شده موضوعی ترجمه‌ها:
    ├── fa/                # account, adminA-D, store, uiA-C
    ├── en/                # معادل‌های کامل انگلیسی
    └── ar/                # معادل‌های کامل عربی
```

## ۳. تغییرات و قابلیت‌های کلیدی

### الف) ساختار ماژولار ترجمه‌ها (Namespaces)
برای جلوگیری از ایجاد فایل‌های غول‌پیکر JSON و افزایش خوانایی، ترجمه‌ها در دسته‌های تخصصی تفکیک شدند:
* `account.json`: پروفایل، تراکنش‌ها، سبد خرید، رفرال و کیف پول.
* `adminA.json` تا `adminD.json`: تمام جداول، فرم‌ها، بنرها و لاگ‌های پنل ادمین.
* `store.json`: فروشگاه، جزئیات بازی، پلن‌های اشتراک و فیلترها.
* `uiA.json` تا `uiC.json`: دیالوگ‌ها، مودال‌ها، نوتیفیکیشن‌ها و فوتر.

### ب) ماژول قالب‌بندی بومی (`format.ts`)
* **قیمت‌ها (`formatPrice`):**
  * فارسی: `۱٬۲۵۰٬۰۰۰ تومان`
  * انگلیسی: `1,250,000 Toman`
  * عربی: `١٬٢٥٠٬٠٠٠ تومان`
* **تاریخ و زمان (`formatDate` / `formatDateTime`):**
  * فارسی: تقویم جلالی (شمسی) مانند `۱۰ آبان ۱۴۰۵`.
  * انگلیسی/عربی: تقویم میلادی مانند `Oct 31, 2026`.
* **حجم فایل‌ها (`formatSize`):**
  * فرمت خودکار گیگابایت و ترابایت بر اساس زبان (`۴۵ GB` / `45 GB`).

### ج) رفع مشکل چشمک زدن جهت صفحه (No Flash of Direction)
* قرار گرفتن اسکریپت مسدودکننده سبک (Blocking Script) در تگ `<head>` فایل `layout.tsx`؛ این اسکریپت قبل از رندر اولیه ری‌اکت، مقدار زبان را از کوکی خوانده و `dir="rtl"` یا `dir="ltr"` را ست می‌کند تا کاربر هیچ پرش جهتی را مشاهده نکند.

### د) سوییچر تعاملی زبان ([`LanguageSwitcher.tsx`](file:///d:/project/DrGame-Ecommerce/frontend/src/components/layout/LanguageSwitcher.tsx))
* همراه با پرچم کشورها، نام بومی زبان و ذخیره در `localStorage` و کوکی ۳۶۵ روزه.
